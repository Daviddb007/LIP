Transparencia y Acceso a la Información

Metodología

El Laboratorio de Inteligencia Pública utiliza el motor SRIE (Sistema de Reconocimiento e Inteligencia Estratégica) para clasificar automáticamente las propuestas ciudadanas contra el marco estratégico del Plan Nacional de Desarrollo vigente. La clasificación se basa en coincidencia de palabras clave, sin intervención humana directa.

Diccionario de Datos

CampoTipoDescripción¿Público?

Los datos agregados excluyen campos identificables. Las exportaciones públicas no incluyen ip_hash.

Modalidades de Participación

  • Participación directa: formulario web en 5 pasos (público, sin autenticación).
  • API pública: integración con sistemas externos mediante API REST autenticada.
